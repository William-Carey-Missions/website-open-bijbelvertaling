# Open Vertaling

Leeswebsite voor de Open Vertaling: een herziening van de Statenvertaling, vrij te gebruiken onder CC0.

De website publiceert één Nederlandse tekst met de Godsnaam HEERE. Leesinstellingen, kanttekeningen, zoeken, voorlezen en downloads zijn beschikbaar. Aanvullende studiegegevens en andere edities worden beheerd op Open Gods Woord.

Over de organisatie: https://williamcareymissions.nl/over-ons

De website en de accountgebonden controle gebruiken de code in js/, server/ en migrations/. De benodigde bouw- en controlescripts staan in scripts/ en tests/.
