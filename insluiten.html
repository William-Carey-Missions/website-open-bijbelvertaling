Citaat insluiten

Plaats teksten uit Gods Woord (Open Vertaling) op je eigen website. De tekst wordt live van openvertaling.nl geladen — er wordt geen kopie gemaakt. Wijzigt de vertaling, dan loopt jouw citaat automatisch mee, en de bron verwijst altijd terug naar de OV.

1. Laad de bibliotheek

Plaats dit één keer in je pagina (bij voorkeur vóór </body>):

<script src="https://openvertaling.nl/embed.js" defer></script>

2. Plaats een citaat

Zet waar je een tekst wilt:

<span data-osv="johannes 3:16"></span>

<span data-osv="psalmen 23:1-4" data-osv-godsnaam="klassiek"></span>

Een bereik mag met een streepje: psalmen 23:1-4. Gebruik de boek-id in kleine letters (bijv. 1johannes, mattheus, psalmen).

Opties

AttribuutWaardeBetekenis
data-osv-numberstrue / falseVersnummers tonen (standaard true)
data-osv-citaattrue / falseCitaatopmaak: rood = God/Christus, « » = directe rede (standaard true)
data-osv-linktrue / falseBronverwijzing naar openvertaling.nl tonen (standaard true)
data-osv-godsnaamov / klassiek / jehovah / yehovah / jhwhWeergave van de Godsnaam: JAHWEH (ov), de HEERE (klassiek), Jehovah, Yehováh of יהוה

Via JavaScript kan ook: OSV.cite('johannes 3:16', {numbers:false}).then(r => el.innerHTML = r.html).
